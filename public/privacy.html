О приложении

EEG Schedule — закрытое веб-приложение для организации расписания исследований. Доступ предоставляется только разрешённым пользователям.

Google OAuth

Для входа приложение использует Google OAuth. После авторизации приложение может получать имя, адрес электронной почты и данные профиля, необходимые для идентификации пользователя и проверки его прав доступа.

Google Calendar и Google Sheets

Приложение использует предоставленный пользователем доступ к Google Calendar для чтения и изменения записей расписания и к Google Sheets для синхронизации расписания из настроенной таблицы. Доступ используется только для функций приложения, инициированных пользователем или необходимых для синхронизации расписания.

Хранение и передача данных

Токены доступа Google не публикуются. Refresh token хранится в защищённой HttpOnly cookie в зашифрованном виде. Приложение не продаёт пользовательские данные и не передаёт их рекламодателям.

Доступ к данным

Доступ к приложению ограничивается списком разрешённых аккаунтов и назначенными ролями. Администратор приложения управляет доступом пользователей.

Отзыв доступа

Пользователь может прекратить использование приложения и отозвать предоставленный Google-доступ в настройках безопасности своего Google Account. Администратор также может удалить доступ пользователя к EEG Schedule.

Контакты

По вопросам конфиденциальности используйте контактный email, указанный на экране согласия Google OAuth.
